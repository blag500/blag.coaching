# Чийт Код в долната лента

**Какво:** Чийт Код вече се отваря от самото приложение — отделно кръгло хапче
вляво от долната лента, със знак на конфигуратор (три плъзгача).

**Как работи:**
- Натискаш хапчето → фонът се замъглява, отгоре излиза прозорец (от долния ляв
  ъгъл) с `/cheatcode/index.html` в рамка. Затваря се с ✕, с тап по фона или Esc.
- Страницата остава една — рамката само я показва, копие няма. Рамката се
  зарежда едва при отваряне.
- При сгъване на лентата (превъртане надолу) хапчето се прибира заедно с нея;
  точката на свиване на лентата е преместена да сочи пак към кръгчето.

**Файлове:** `src/components/CheatCode/CheatCodeSheet.{jsx,module.css}`,
`src/components/BottomNav/*`, ключове `nav.cheatcode`, `nav.cheatcodeClose`.

**Проверено:** `npm run build` минава; Playwright (mobile) в тъмна и светла тема —
хапчето е на мястото си, прозорецът се отваря, страницата се зарежда, ✕ го затваря.

**Къде е:** клон `claude/cheatcode-pill`, не е на main → не е деплойнато.
