# Клип „Числата“

15 с, 1920×1080, без звук. Продуктова анимация по референцията с терминала
(optimaizr): глави с моно етикет, текст, който се изписва, графика от точки,
голямо число в точкова матрица, живият продукт, финал със знака.

| с | глава | какво |
|---|---|---|
| 0–4 | 01 МЕНЮТО | стрелка и курсор; „Менюто казва какво има в кутията, но не и колко.“ |
| 4–7 | 02 ГРАМОВЕТЕ | 125 кутии на Телешкия боул (5 × 5 × 5 стъпки), подредени по калории; скенерът спира на средната |
| 7–9.6 | 03 ЧИСЛОТО | 754 ккал в точкова матрица; 66 г протеин · 81 г · 17 г · 6,20 € |
| 9.6–12.55 | 04 НА ЖИВО | конфигураторът: кайма 250 → 350, ориз 100 → 75; цената скача по десет цента |
| 12.55–14 | 05 ЧИСЛАТА | „Храната, която си знае числата.“ |
| 14–15 | | плочката със знака и словният знак зад курсора |

Всяко число е сметнато в `scene.js` от данните на Телешкия боул в
`cheatcode/page.html` (Р5 в `docs/DECISIONS.md`). Ако там се смени цена или
етикет, таблицата горе в `scene.js` се сверява.

## Пускане

Шрифтовете идват от Google Fonts, значи трябва мрежа.

```bash
python -m http.server 8899 --bind 127.0.0.1 --directory cheatcode/reel-product
node cheatcode/reel-product/render.mjs --sheet 2 6.9 8.8 11.6 14.9   # кадри в sheet/
node cheatcode/reel-product/render.mjs                               # → out.mp4
```

Пуска се от корена на repo-то (Playwright е там). Изходът пада до клипа.

За гледане без рендер: `http://127.0.0.1:8899/` с пулта, `#t=8.8` за един
кадър, `#sheet=1,4.8,7.4` за контактен лист, `?z=660` за фиксирана ширина.
